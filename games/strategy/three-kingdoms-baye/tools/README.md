# 词典绿屏高清重绘

游戏逻辑仍使用仓库内原版引擎和原版资源。逻辑分辨率仍为 160 × 96，输入坐标、地图、城池坐标、数值、存档格式均不变。

屏幕使用最初的 `#b8c58d` 词典绿色。`display-enhance.js` 只改变最终显示层，原始点阵模式仍直接呈现原帧。

## 已批准的地图重制

`map-art.js` 在原显示层上接入独立的山水、城楼和人物头像素材。城池坐标直接从原版 `C_MAP` 读取，道路使用原版 `CITY_LINKR` 连接数据，按原视口坐标滚动。地形是保持总体布局的美术重绘，线条细节不属于逐像素复刻。

城池归属从固定原版 WASM 的 `g_Cities` 只读获取：本方黑底旗、敌方空心旗、无主空心圆。同姓势力显示君主全名。资源图标的本方/敌方/无主编号必须与读取的归属一致才显示旗号，避免错误内存布局或陈旧状态产生虚假归属。显示层不调用、不修改游戏逻辑和内存。

每个屏幕独立维护图片覆盖区，复制、保存、恢复和遮挡与原引擎同步。最终帧逐像素检查原图是否仍然可见，菜单或文字占用的区域不允许被重制图片覆盖。原始模式立即回到原帧。素材列表与生成记录见 `../assets/hd/remaster-notes.md`。

地图显示元数据可在游戏目录中重复提取：`node tools/build-map-art.cjs`。

战场由 `battle-art.js` 按原版 16 × 16 地形格与单位绘制通知重画。2026-09-27 批准的第二张墨线样稿保存在 `assets/hd/battle-woodcut-reference.png`：城墙从原图棋盘纹及边缘数据绘出城垛、角楼和门楼，地面只加细小墨线草纹；人物使用同风格八格黑白图集 `assets/hd/battle-woodcut-units.png`，按原版单位的绘制位置、左右朝向与八组形态分类呈现，图片未加载时回退原图矢量轮廓。天气与底部问号使用清晰矢量图标。每格先核对原始最终帧，文字、选择框或其他覆盖内容仍显示原图。元数据可用 `node tools/build-battle-art.cjs` 从原版词典资源重新生成；`battle-art.test.cjs` 检查野战、城池攻防及地图重画后的旧单位清除。

头像图集注册在 `assets/hd/general-portraits.json`，按原剧本、人物索引及原始位图指纹匹配。同一位图跨剧本共用重绘图，不同位图不混用。人物页和结果弹窗沿用同一映射。`tools/portrait-batch-plan.json` 保存全量补图清单，`assets/hd/portrait-batch-prompts.json` 保存内置 image_gen 的提示词。注册表的 `complete: true` 会强制构建器检查全部 800 个资源条目无遗漏且图集存在。

通过本地服务打开 `tools/portrait-review.html` 可按图集对比原图与重绘图，并核对加载数量及未映射数。运行 `node --test *.test.cjs` 验证覆盖、身份映射、裁切范围以及引擎约束。

`vector-art.js` 将原图分解为不同灰度的闭合轮廓，再绘制直线和二次贝塞尔路径。每个候选轮廓都核对原始像素中心的覆盖区间和边界，曲线使用解析交点验证；不合格就保留原路径。斜向道路中共用的连接顶点固定保留，避免圆角造成视觉断裂。地图地形、城池、头像和动画不移动，不通过位图模糊滤镜插值。原图缺少的细节不会凭空添加。

主菜单和四个剧本插画使用单独制作的高清黑白素材；图片中的文字按原位置重新排印，选中框来自原引擎的菜单动画编号。只有原始画面头部指纹匹配时才显示相应插画，退出菜单后自动停止覆盖。详情及生成提示词见 `../assets/hd/README.md`。

通过 `GamChinese` / `GamAscii` 明确绘制的文字在原有文字格内按屏幕分辨率绘制。绘制前将完整字模与最终帧逐像素核对；遮挡、灰度、裁切或不匹配时保留原图。复制屏幕、恢复屏幕和局部反白同步文字标记。渲染器只读取 WASM 内存，不调用游戏逻辑函数。切换「原始点阵」不会重新启动游戏。

WASD 和方向键发送相同的原版方向指令，S 向下，F 查找，H 帮助，Enter 确认，Space/Escape 返回。下拉框、输入控件、输入法组合及浏览器快捷键不被拦截；触屏方向键会重新聚焦画布。

## 引擎构建

原始 `engine/baye.wasm` 原封不动保留，SHA-256 为：

`f65723e06946e5a824e0890cd2fe07a1b1488151f6c5abbbc0de2599f491c5a8`

`engine/baye-hd.wasm` 只增加绘制通知。使用 Binaryen 的 `wasm-dis` / `wasm-as` 重建：

```sh
node tools/build-hd-engine.cjs /path/to/binaryen/bin /path/to/scratch
```

脚本验证：删除新增的通知和导入后，WAT 必须与原始反汇编逐字相同；原有导入与导出不变。结果及哈希记录在 `engine/hd-build.json`。通知在 Asyncify 栈回放时跳过，避免重复绘制。

修改后在本目录运行：

```sh
node --test *.test.cjs
```

自动检查覆盖原引擎哈希、原资源、所有地图瓦片/城市标记/唯一头像的轮廓覆盖、文字反白、菜单识别和键盘路由。浏览器检查主菜单、剧本、君主选择、地图与城池菜单，两种显示模式及 WASD/方向键选择。
