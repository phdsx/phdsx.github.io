# 炸弹超人：截图参考网页复刻

## 启动

在本目录运行 `npm install`、`npm run dev`，打开终端所示地址。打包用 `npm run build`，产物写入 `play/`，可作为本仓库静态站点的游戏入口；逻辑验证用 `npm test`。页面初始展示参考画面对照，点击“开始对战”进入 1 人对 3 名电脑的本地对战。方向键或 WASD 移动，空格放炸弹，P 暂停，F2 切换对照画面。页面按键区可逐个重新绑定，设置保存在浏览器。

## 依据与已确认规则

视觉依据是用户所附的炸弹超人截图。画面棋盘 17 × 13 格，约 40 像素一格，左上角约 `(53,39)`。石墩、砖墙位置显式写在 `src/config.ts`，场景与角色均以代码重绘为独立瓦片/精灵，没有使用整图背景。截图未给出原始精灵表与动态画面，所有角色背面、行走帧、炸弹、火焰、瓦片和声音都是风格相近的替代素材。

[原版游戏规则介绍](https://www.ourgame.com/game/game-intro-dly/bombman.html)确认：方向键可控制移动，原版放弹键可自定义且默认 Z；每人起始一弹，初始火力半径两格，炸弹放下约两秒后爆炸；基础道具“炸弹”加同时放置数量，“火焰”加一格半径，“加速”每件加初始速度的 25%；火焰不分敌我；原版 2～6 人。截图构图采用这一版的视觉，玩法实现选取其基础本地对战子集。由于用户指定空格放弹，本作默认空格，并可自行改键。

## 可调暂定值与已知差异

`src/config.ts` 集中列出可调值。移动基础速度 112 px/s、火焰持续 430 ms、道具掉率 34%、拐弯辅助 9 px、AI 决策周期和碰撞脚底半径均为暂定值，未声称是原版精确参数。原版炸弹两秒、初始火力两格和加速 25% 有官方依据。

原版还有 11 种道具、2～6 人联机、分组、购买财富道具、功能键、踢/打/扔炸弹、中毒和超时外围石化。本版本只有三种基础道具，超时判平局，没有联机或这些高级道具。截图中骷髅道具只在静态对照模式中出现，正常对战不生成，避免出现无效果的道具。电脑使用与玩家相同的移动、碰撞、放弹和伤害规则，依据公开的炸弹/地图状态做危险预测与寻路。声音使用 Web Audio 合成替代音效。

已将原图棋盘与浏览器实际画面各整理为 680 × 520 像素，见[对照图](../../../audit-evidence/bombman-comparison.png)。截图中的原版人物面部、发型和炸弹火星比重绘版本更细，原版石墩高光及围墙的斜向反光也更复杂；目前只能按单帧视觉近似，动画节奏待录屏校准。浏览器截图在采集时发生轻微缩放，因此对照图中右侧经过尺寸归一化，不用于逐像素误差宣称。

## 架构

`src/model.ts` 是与 Phaser 渲染分离的确定性对战状态，`src/main.ts` 管输入与展示，`src/art.ts` 生成独立像素纹理。这一划分便于之后把本地输入替换为网络同步输入。对照模式独立于正常回合，不改变进行中的对战状态。
