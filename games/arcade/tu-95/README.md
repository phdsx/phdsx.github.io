# TU-95 飞行训练

独立 HTML5 侧视飞行游戏，参考 TU-95 的起飞、巡航、襟翼、起落架与着陆玩法。全中文，无广告、无远程脚本、无外部字体、无运行时依赖。飞机与远景为本次新生成的素材。

直接打开 `index.html` 即可游玩；也可从站点根目录运行 `node scripts/serve-site.mjs 8194`，访问 `/games/arcade/tu-95/index.html`。入口同时已接入 `games.html`、首页搜索目录及中文导航。

- ↑ / W 增加油门，↓ / S 减少油门，松开保持当前油门。
- ← / A 抬头，→ / D 低头，松开保持当前姿态。
- G 切换起落架，F 循环襟翼（收起 → 起飞 → 着陆）。
- 空格按住刹车，P / Esc 暂停，R 重飞；页面失焦自动暂停并清除输入。
- 手机支持同时按住俯仰、油门等按钮；起落架、襟翼点击仪表按钮切换。

初始为起飞襟翼和放下的起落架。空速达到约 220 km/h 时轻抬头；巡航建议高度 120～250 米。进近提前收油门、放下起落架、切换着陆襟翼；轻柔接地后按住刹车。目标跑道停稳才会结算。

三条任务依次为晴空长跑道、逆风转场、黄昏阵风短跑道。成绩以 `phdsx-tu95-v1` 保存，包含版本和按航线 ID 索引的星级/分数。存储被禁用时仍可单次游玩。重新加载从首关准备界面开始，已解锁航线可在下拉框选择。

## 验证

`node games/arcade/tu-95/physics.test.cjs`：通过玩家同等输入完成三条航线、固定步进可重复性、暂停、起落架保护、五种着陆失败、失速、损坏存档。

`node games/arcade/tu-95/browser-test.cjs`：需要已有 Playwright 与 Chromium，使用临时静态服务器和隔离浏览器，无用户浏览器资料。通过真实键盘完成首关，验证暂停、重飞、存档解锁、声音、原生双指触控、320/390/720/1080 宽度及游戏列表入口。截图与结果在 `docs/audit/evidence/tu-95/`。游戏外部请求必须为空；目录页保留站点已有统计配置。

游戏模型为可玩性设计的简化飞行规则，未作真实飞行器工程模拟。实体手机性能、Safari 和读屏体验未实机验证。
