# 像素坦克大战

原有公开入口保持为 `games/arcade/tank/index.html`，游戏厅动作街机分类仍使用同一链接。纯原生 HTML / CSS / JavaScript，没有 npm 依赖、构建步骤或外部素材；可直接打开 HTML，也可以在仓库根目录运行：

```sh
node games/arcade/tank/serve.cjs
```

访问 `http://localhost:8080/games.html?category=arcade`，选择坦克大战。关闭预览服务使用 Ctrl+C。

## 操作与规则

- 方向键 / WASD：四方向移动。多键同时按下时，以最后按下的方向为准。
- 空格 / J：开火，按住连续射击，可以同时移动。
- P / Esc 或暂停按钮：暂停 / 继续。窗口失焦、页面隐藏时自动暂停并清除按键。
- 手机：方向按钮和开火按钮支持同时按住，使用独立 pointerId 和指针捕获。
- 三条生命共用三关；每次复活保护 3 秒，出生动画 0.7 秒。生命耗尽或基地遭任意炮弹命中即失败。
- 每关 12 / 16 / 20 辆敌军，同屏上限 4 / 5 / 6。普通、快速、装甲分别计 100 / 200 / 400 分，装甲需三次命中。
- 砖墙以 32px 宽、16px 深的条带逐步破坏。钢墙挡普通炮弹；水挡坦克、允许炮弹通过；草遮挡坦克与炮弹。
- ★ 升至火力 2 时增加弹速并允许两枚炮弹同时在场；升至 3 时可以击破钢墙。升级维持至本条生命结束。
- ◇ 护盾保护 10 秒；✹ 消灭当前已出生敌军，尚未出生的敌军继续出现。
- 每关有一枚初始升级道具；累计每击毁四辆敌军按升级、护盾、爆破顺序掉落道具。道具限时存在，最后 5 秒闪烁；拾取额外计 50 分。
- 全歼当前关卡后点击“下一关”；第三关胜利有明确结束画面。“重新开始”重置整轮战役。
- 声音默认关闭。点击声音按钮后才创建 Web Audio，音效均为本地合成；离开页面时关闭音频。

## 代码职责

| 文件 | 职责 |
| --- | --- |
| `maps.js` | 三张 13 × 13 地图，展开成 26 × 26 的细分碰撞格 |
| `engine.js` | 无 DOM 的规则引擎：碰撞、路径选择、波次、生命、道具、结算 |
| `render.js` | 416 × 416 Canvas 像素绘制，不拉伸比例 |
| `game.js` | 输入、界面、音效和页面生命周期；120 Hz 固定步进、单一 RAF |

敌军使用 Dijkstra 寻路，钢与水不可通过，砖墙带有较高路径成本，遇砖墙会射击开路。坦克移动逐步检查 AABB；转弯时沿一个轴对齐附近通道，避免瞬移或斜向移动。子弹每个子步最多移动 2px，敌我弹相遇、坦克、墙、基地依次处理碰撞。页面离开时取消 RAF、清除输入、AbortController 移除监听、关闭音频；BFCache 恢复时创建单个新实例。

旧版在共享 `classic.js` 的坦克规则分支与 `classic-3d.mjs` 的坦克几何场景已删除，本页面也不再加载共享 Three.js bundle；bundle 用原项目脚本重新生成。其他六款经典游戏及宝石图集保留。游戏厅坦克图标仍被入口使用，保留。

## 验证

规则验证：

```sh
node games/arcade/tank/engine.test.cjs
node games/classic/classic.test.cjs
node games/classic/classic-3d.test.cjs
node scripts/check-navigation.mjs
```

`engine.test.cjs` 覆盖 15 组规则，包括砖墙两层破坏、高速弹、防重叠、地形、钢墙、弹弹相撞、射击限制、装甲与计分、道具、出生占用、复活、基地和生命失败、三关结算、暂停与重置。三张地图各模拟敌军推进 25 秒，检查真实射击、向基地推进、砖墙破坏及每步碰撞。

本地服务启动后打开 `http://localhost:8080/games/arcade/tank/browser-tests.html`。此验证页在 iframe 中加载真实入口，使用浏览器 DOM 输入和实际 RAF，检查移动同时开火、按键优先级、暂停/失焦、多指输入、出生与敌军运动、界面结算、重复重开、pagehide/pageshow 清理和画布比例。验证页不被公开游戏入口加载。

2026-09-28 在 Codex 内置 Chromium 中实际运行上述验证：10 组通过、0 组失败，页面错误监听未捕获异常，结果保存为 `browser-validation.png`。也实际从游戏厅进入正式页面，观察到敌军运动、射击、玩家损失生命及复活、基地失败，检查了暂停、重开和声音开关。另使用三关各四个随机种子各运行 40 秒敌军模拟，均推进到地图下部并持续开火。

死亡、关卡结算及最终胜利的浏览器验证使用受控状态夹具，不等同于人工无辅助连续打通三关。触控事件已自动验证，但尚未在实体手机进行双指试玩；合成音效尚未做人工听音检查。

全站链接检查另有现存问题：`games/arcade/bombman/index.html` 的 `/src/main.ts` 引用，不属于此游戏的修改范围。
