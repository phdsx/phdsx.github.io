DiPlay

安卓车机 CarPlay 接收器

Android 7.1+CarPlay公开预览版

让兼容的比亚迪安卓车机接收 iPhone 的 CarPlay，适合希望在原车屏幕使用导航、音乐与电话的用户。

维护者
shihabal3amri
核对版本 / 发布日期
0.2.16（公开预览） · 2026-10-09
运行要求
允许安装 APK 的比亚迪车机，Android 7.1+（API 25+），配合 iPhone 使用。
使用与源码
开源，GPL-3.0；部分界面组件涉及 AGPL-3.0，详见项目许可。

主要功能

  • 提供 USB 有线、车机热点、Wi-Fi Direct 和同一局域网等连接方式。
  • 可调分辨率、帧率、图标与文字大小，提供中文界面和深浅主题。
  • 部分固件支持仪表 / HUD 导航；可选车辆数据功能需要已授权的网络 ADB。

兼容性说明：未经 Apple 认证；Android 7.1–8.1 尚待实车确认，其他汽车品牌不在支持范围内，未来 iOS 兼容性也不保证。

安装与连接
  1. 停车后从发行页获取 DiPlay-0.2.16.apk，按车机允许的方式安装；APK 安装在车机上，手机端无需安装。
  2. 关闭其他手机投屏应用，按实际使用功能授权蓝牙、Wi-Fi 和麦克风等权限；核心 CarPlay 连接不要求 ADB。
  3. 无线连接可在设置中配置车机热点并与 iPhone 配对；有线连接需使用支持数据传输的 USB 端口和数据线。具体步骤见安装文档。

HG

红果短剧电脑版

渠道有数独立维护的非官方 Windows 短剧播放器

Windows 10 / 11 x64免费使用无需安卓模拟器

在 Windows 电脑上搜索短剧、收藏片单并接着上次观看，直接安装桌面程序即可使用，适合习惯用电脑追剧的用户。

维护者
渠道有数（独立维护）
核对版本 / 发布日期
1.0.12 · 2026-10-07
运行要求
Windows 10 / 11，x64（64 位）；需要 Microsoft WebView2 运行环境。
使用与源码
免费使用；此仓库用于发行和反馈，应用源码未公开。

主要功能

  • 按分类浏览、搜索剧名、手动选集，并按标题查找同系列的其他季。
  • 支持自动连播、最高 3 倍速、本机收藏和观看进度续播。
  • 可自定义老板键（默认 Ctrl+Shift+B），隐藏时暂停、恢复窗口后续播。

使用说明：收藏和观看记录仅保存在当前电脑，不与手机 App 或其他电脑同步；剧集与播放可用性取决于内容来源和网络情况。

安装与更新
  1. 从发行页下载 hongguo-1.0.12-windows-x86_64-setup.exe（约 108.6 MiB）；源码 ZIP、.sig 和 latest.json 并非安装包。
  2. 按提示安装。缺少 WebView2 时安装程序会联网补装；补装失败可从微软官网获取 x64 版 WebView2 Runtime 后重试。
  3. 更新前在软件设置中完全退出程序，再运行安装包。当前安装包未配置 Windows 发布者代码签名，请对照原发行页的来源和 SHA-256 摘要核验文件。
