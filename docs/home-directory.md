# 首页栏目目录

首页承担站内导航：顶部只提供“栏目、关于、GitHub”，各栏目通过目录进入自己的页面。AI 雷达的评分和预测继续只在独立页面加载。

## 信息层级

- 简短的个人介绍沿用原有深色、浅绿配色和钛金属环配图。
- 栏目按“实用工具、玩与漫游、阅读记录、专题资料”筛选，可与关键词搜索组合使用。
- 电脑显示三列，平板显示两列，手机改为紧凑的单列入口。更多栏目随网格自然延伸，无需增加顶部导航项。
- 没有匹配结果时显示空结果提示和重置按钮；关闭 JavaScript 时，九个静态链接仍然可用，搜索与筛选控件隐藏。

## 新增栏目

1. 在 `index.html` 的 `#section-grid` 中添加一个 `.portal-card` 链接，填写真实页面路径、标题和说明。
2. 设置 `data-home-section` 为 `tools`、`play`、`reading` 或 `topics`；如需新的大类，同时补充对应的筛选按钮。
3. 在 `data-keywords` 中添加别名、用途和英文名。搜索按空格分词、忽略英文大小写，并兼容全角英文字符。
4. 使用现有图标目录中的素材，图标为空替代文本，栏目由文字说明。

页面从卡片读取标题、类别和关键词，不维护第二份 JavaScript 栏目清单。栏目总数、分类数量和筛选结果自动统计；无需修改顶部导航或搜索脚本。

## 操作与检查

`Ctrl K` / `⌘ K` 聚焦搜索框，`Escape` 清空关键词，搜索框内 `Enter` 聚焦第一个匹配的栏目链接，再按一次进入。清除筛选同时重置关键词和类别。

修改后运行 `node --test scripts/test-home-directory.mjs`、`node scripts/check-navigation.mjs` 和 `node scripts/check-site-links.mjs`。浏览器检查电脑、平板、手机的布局，以及分类、空结果重置和 AI 雷达独立入口。
