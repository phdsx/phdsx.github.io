# PHDSX 首页 UI 优化设计稿

## 目标

将现有首页优化为“清爽工作台”式个人门户：搜索和常用工具保持首要位置，同时让游戏、博客、小说和黄页成为清晰可浏览的第二层内容。保留现有路由、Clarity 统计、固定侧栏和本地静态页面架构，不增加账号、消息或后端能力。

## 用户结果

- 用户打开首页后，能在首屏快速搜索或打开常用工具。
- 用户无需依赖搜索，也能通过明确的分类看到图片、文本、时间和趣味工具。
- 用户可以从首页发现游戏、博客、小说连载和黄页入口，且这些内容不会与工具入口争夺同一层级。
- 用户在桌面和手机上都能理解页面层级，主要入口不被挤压或遮挡。

## 页面结构

1. 固定左侧站点导航：维持首页、工具、游戏、博客、黄页和小说连载入口。
2. 首屏搜索区：保留分类筛选、热门搜索、键盘提示和结果浮层；标题缩短为直接表达搜索用途的单行主标题。
3. 首屏快捷区：将热门入口、工具直达和站点概览整理为同一组轻量工作台模块，弱化边框和嵌套卡片感。
4. 主内容区：左侧展示按场景分组的工具入口，右侧展示最新内容、游戏推荐、小说和黄页摘要。
5. 内容分区：游戏保留真实图片卡片；博客、小说和黄页使用轻量列表，保持可扫描性。
6. 页脚：保留现有站点身份信息，不添加营销式说明。

## 视觉系统

- 继续使用现有设计变量：浅灰页面底色、白色内容面、深色文字、品牌蓝、青色和橙色强调色。
- 以留白、分组、标题层级和细分隔线完成信息组织，减少大面积阴影和重复边框。
- 卡片只用于真正独立的入口或媒体对象；普通列表使用行分隔，不把列表项再包装成卡片。
- 正文基准字号保持 14-16px，标题采用紧凑但清晰的层级，不使用负字距或随视口缩放字号。
- 保留现有图标素材，图片统一使用固定尺寸和 `object-fit`，避免页面跳动。

## 响应式行为

- 桌面端使用 208px 固定侧栏，主内容最大宽度 1400px。
- 900px 以下侧栏转为顶部导航，搜索、快捷区和内容区改为单列或双列自适应布局。
- 620px 以下优先顺序为搜索、常用入口、工具分类、游戏、最新内容、小说和黄页；分类筛选允许横向滚动但不出现页面横向溢出。
- 交互控件保持可点击尺寸，长标题允许换行，不使用会截断关键信息的固定高度。

## 交互与内容约束

- 首页搜索继续使用 `assets/site.js` 的统一搜索索引，分类、热门搜索、键盘导航和空结果状态保持可用。
- 所有首页入口继续使用现有相对路径，不改动已有页面 URL。
- 不新增登录、消息、收藏、评论、排行榜或需要后端的功能。
- 保留每个页面现有 Clarity 统计代码，不改变统计 ID。

## 验收标准

1. 首页首屏同时能看到搜索入口和一组清晰的常用内容入口。
2. 工具、游戏、博客、小说和黄页在视觉上属于同一套设计系统，但层级和内容密度有明确差异。
3. 输入“雷”能展示“雷劈计算器”，分类筛选和热门搜索仍可正常工作。
4. 桌面端固定侧栏不覆盖首页内容；移动端无横向滚动，搜索与入口文本不溢出。
5. 首页所有主要链接可正常打开，图片加载失败时不造成布局塌陷。
6. 页面保持静态 HTML/CSS/JavaScript 兼容，不引入新的运行时依赖。
