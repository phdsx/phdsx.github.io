## iFlowGo 坐标搜索（2026-10-09）

默认新增“iFlowGo · 坐标搜索”。首次打开经纬度为空，地图加载、地点快捷选择与条件编辑均不请求宝可梦或设施数据。输入合法经纬度，或点击时代广场、中央公园 Bethesda 喷泉、帝国大厦、中央车站、布鲁克林大桥、自由女神像，再点击“搜索”。支持 1 / 2 / 3 / 5 / 10 / 15 km 半径及宝可梦、团体战、补给站任务多选。

搜索后每五分钟按上次提交条件刷新，显示倒计时并支持手动刷新。修改输入不会改变正在自动刷新的搜索；再次搜索才应用新条件。每次打开仍需重新搜索。地图、列表和数量使用相同的视野与筛选；宝可梦支持名称、编号、IV、CP、等级、形态、剩余时间筛选，团体战与任务支持地点名称筛选。刷新失败保留同一次搜索的缓存，换地点不沿用旧地点记录，到期宝可梦和团体战在本地移除。

实时查询由本地服务 / Cloudflare Worker 的 `api/radar-search` 转发。纯 GitHub Pages 不能执行任意坐标查询，上游也未开放跨域；需配置 `POKEMON_RADAR_API_ORIGIN` 连接已部署的 Worker，见 [部署说明](deployment/README.md#实时坐标搜索)。没有连接时明确提示，绝不使用固定试点快照冒充本次搜索。旧有区域来源保留，也只在点击搜索后开始读取。

以下原有来源规则适用于区域快照模式；iFlowGo 坐标搜索的团体战与其他已选类别一起每五分钟更新。

中文 React / TypeScript / MapLibre 网页。按照整个地图视野与纽约市官方行政边界的空间关系选择宝可梦来源：默认纽约市内 NYC PokéMap；伦敦、新加坡、悉尼和温哥华在固定请求窗口使用本地 PokéMap；旧金山为 iFlowGo 2 km 试点；剩余范围使用 Pokémon GO Coordinates，跨区域分别裁剪后合并。数据源设置提供自动模式及所有已接入来源的手动选择。手动模式只显示所选来源，不叠加其他来源，不自动换源。地图、列表和数量使用同一份视野内筛选结果。

宝可梦、Stop 任务和火箭队活动每 5 分钟更新来源快照，提供倒计时和手动刷新。地图拖动、缩放、图层切换、筛选和排序只使用缓存，不发起上游请求，也不弹出获取成功提示。暂时失败标注旧缓存，授权失效不展示锁定坐标，到期记录在本地移除。

**道馆目录及团体战只在打开页面时读取一次**，独立于五分钟刷新和手动刷新。PogoMap.info 提供实际社区目录，NYC PokéMap 提供团体战；分别保留原始记录和来源。社区队伍不代表实时占领情况；未知的照片、守馆宝可梦和空位如实显示未知。名称、坐标均一致且匹配唯一时才合并两个来源。

当前 Windows 本地网页通过标准 PowerShell HTTP 客户端新建匿名会话并请求已核实的公开目录接口，实际成功取得纽约市内 205 条社区记录。此访问方式不使用用户 Cookie、浏览器验证凭证或账号。Node / Worker HTTP 客户端曾收到 Cloudflare 403；本地兼容读取已经解决当前预览的访问问题，部署环境的直接访问仍需单独验证。

道馆详情使用独立大面板，桌面宽度最高 760px，手机使用接近全屏的布局；长内容可滚动，坐标、来源和原始 ID 始终可见，支持 Escape 关闭。道馆列表显示本次目录取得时间，不将社区信息当作实时游戏状态。读取失败时明确显示原因，固定参考目录另外注明采集日期，不能冒充本次取得的数据。

补给站的任务与活动合并为一个地点标记，火箭队活动优先显示为 R。支持独立图层开关、地点名称筛选、列表和详情。新增四个城市的任务、活动和打开时读取的团体战，以及纽约静态 PogoMap Stop 目录；旧金山 Radar 只接入已核实的任务。固定请求窗口不代表扫描覆盖，未知覆盖和截断明确说明，没有已核实的全球完整设施接口。

宝可梦列表、详情、图鉴筛选和地图标记显示真实配图，1347 张 WebP 已打包在 public/pokemon-artwork。已核实的地区形态匹配对应图片；未核实或未收录的形态明确标注图鉴示意。图片来源与版权、接口字段、覆盖和访问限制见 DATA_SOURCES.md。

在页面“数据源设置”中选择“宝可梦数据源”：自动按地区选择、NYC、iFlowGo 纽约/旧金山试点、London、SG、Sydney、Van 或 PGC。选择保存在本浏览器，刷新后恢复；切换直接使用缓存并保留筛选条件。手动选择不会随地图移动改变；视野超出来源的已接入范围时提示，并提供“前往此来源范围”。只有自动模式按地理区域分工，手动模式始终只用所选来源。Gym、Stop 和火箭队按各自地理来源展示，不受该选项影响。坐标锁定、授权与失败状态仍如实显示。

## 启动

需要 Node.js 22.13+；Windows 本地目录读取需要 PowerShell 7（pwsh.exe 在 PATH 中）。当前工作区依赖已安装。

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

打开 http://127.0.0.1:5173/ 。本地标准 HTTP 读取仅在 Windows 开发预览启用，其他环境使用公开 fetch 路由并如实显示访问结果。
