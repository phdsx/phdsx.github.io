# 香山 · 秋日山行

本站已接入「3D云游 → 中国 → 北京」。`index.html` 提供站点导航，原三维工作区保留为 `scene.html`；以下为原项目说明。

可本地运行的 Three.js 3D 地理游览项目。真实地形与路径已接入，重点近景为勤政殿前区。当前版本：v2，2026-10-04。

**本版本是有来源的交互原型，尚未达到摄影级、全园建筑完整或测绘级 1∶1 复原。** “1 单位 = 1 米”描述模型单位，不等于所有对象都经过实测。完整范围见 [ACCURACY.md](ACCURACY.md)。

## 启动

解压后，在含 `index.html` 的 `xiangshan` 目录打开终端：

```sh
python -m http.server 8000
```

浏览器打开 **http://localhost:8000**。Windows 也可双击 `start.bat`；如果安装了 Node.js，可运行 `node server.mjs`。

请使用新版 Edge、Chrome 或 Firefox，并启用 WebGL 2 / 硬件加速。不要直接双击 `index.html`；浏览器会限制 `file://` 读取二进制高程和 ES modules。端口占用时改用 `python -m http.server 8001`，再访问相应端口。

**运行时无外部网络依赖，不需要 API Key、npm install 或构建步骤。** Three.js、控制器、高程、地图快照、照片和材质均在 `assets/` 内。来源说明里的外链仅用于查阅。重新下载或重投影数据才需要网络与额外 Python 库。

## 游览

- 全园鸟瞰：左键拖动旋转、滚轮缩放、右键平移；触屏单指旋转、双指缩放 / 平移。
- 步行游览：WASD / 方向键移动，拖动观察，Shift 加速，Esc 返回鸟瞰；触屏有方向按钮。视点高 1.68 m。
- 下方五个景点按钮平滑跳转。步行模式下会落到该景点最近的真实地图道路上。
- 右侧按钮：回到全园、显示地名、显示东门至香炉峰路线、高画质 / 省电、全屏。
- 右上角 ⓘ：查看准确性边界和参考照片。

步行使用地图道路走廊、防越界和建筑轮廓的基本约束，不是完整物理引擎。殿前铺地、10 级示意台阶和拱桥共用可见模型的高度定义，视点对高度变化做平滑处理；其他登山路段仍用连续地形近似。踏步数量和尺寸未经现场测量。路线是数据中连通步道的计算结果，**不是现实游园通行、安全或开放状态指南**。

## 技术说明

- WGS84 经纬度经 **EPSG:32650 / WGS84 UTM 50N** 转换，原点为 116.1815° E、39.989° N。x 向东、z 向南、y 为 DSM 高程；高度放大系数严格为 1。
- 原始 GLO-30 为约 1 角秒，香山纬度约 24 × 31 m；20 m 渲染重采样和重点区 2 m 网格只改善显示，不增加测量精度。
- 模型使用 ACES 色调映射、sRGB 色彩输出、单一西南侧下午太阳、环境照明和远距离空气透视；不使用 Bloom。
- 树木为程序化美术近似。远景用相机朝向替身，高画质近景最多 112 株、省电最多 56 株完整枝叶实例；按空间分区合批、视锥裁剪与距离 LOD 控制成本，近景才投射阴影。推测的秋色与针阔叶比例按空间片区变化，树冠有宽度、明暗和镜像差异。静止视角复用阴影贴图，镜头位置或树木 LOD 改变时更新。
- 静翠湖与殿前池在高画质且距镜头 180 m 内启用 512² 平面场景反射，同时最多一处；静止镜头复用反射缓存，省电模式使用环境反射。波纹由解析法线生成，水位仍为推测。
- 建筑几何按材质合批；场景没有声称来源真实的通用中国建筑 GLB。尚无获得授权的香山实景扫描模型，所以没有伪造模型来源。
- 资源随包一次载入，植被按分区控制显示 / LOD；**尚未实现按需网络分区流式加载**。小型当前数据包可离线运行，后续大规模扫描资源应采用 glTF + Meshopt / KTX2。
- 如材质加载失败，会提示并退回基础颜色；核心数据缺失或 WebGL 无法启动时显示错误说明。

## 修改与验证

无需编译，编辑代码后刷新页面。开发控制台可调用 `window.xiangshan.getState()` 读取真实帧率、draw calls、三角形数量、视角、模式、错误和 Three.js 版本。`window.xiangshan.flyTo('hall')` 等方法用于检查指定景点。相关接口仅用于本地场景调试。

本轮改动见 [CHANGELOG.md](CHANGELOG.md)。交付前实际测试情况见 [validation/REPORT.md](validation/REPORT.md)。帧率与分辨率、浏览器、GPU、设备电源策略相关，不承诺所有设备 60 FPS。
