# 精度、分期与尚未完成的部分

## 截面和宣称边界

项目目标为乾隆五十一年（1786），依据同期西洋楼铜版图。不是现代遗址场景。史料没有齐备，**当前是可运行的历史近似研究版，不是完整园林、照片级或测绘级复原**。A表示某个事实的证据充分，不表示整个模型精确。每个点位单列外观、室内、色彩、陈设。

|---|---|---|
| 三园方位、主要景点名称 | A，官方与图档支持 | 当代辅助范围不是1786分期边界 |

## 米制坐标

原点 WGS84 (116.298°E, 40.006°N)。局部计算：

`X=(lon−116.298)×111320×cos(40.006°)`；`Z=−(lat−40.006)×111320`。

+X向东，+Z向南，+Y向上，1世界单位=1米。OSM不是GCJ-02或BD-09，未混入高德/百度图坐标。只用了局部等距近似，几千米范围仍存在投影误差；数据保留两位小数是计算格式，**不代表厘米测量精度**。脚本<2cm为数值往返误差，不能当作定位精度。

高程为相对模型基准：湖面0米，常规地面约0.62米，展示桥面0.66米；未核实海拔与历史整地。点位公开地图误差未知，手工估算点位可能有数十米误差；建筑宽、高和台基未经实测，未编造误差百分数。园林未被按构图压缩，但模型尺寸估计仍会造成局部不一致。

## 几何及游览限制

自建曲面屋顶、檐口、脊线、柱网、窗棂、立面拱窗、线脚、台阶、石材立体卷曲与叠盘。雕刻只是结构化简化线条，未制作圆明园石雕的文物级模型。大水法的铜鹿、铜犬、塔冠雕塑和兽首没有精雕，用说明明确缺失，喷水轨迹仅示意水法。

47个点位不是47处完整建筑群；多数中式景群只制作主要外观及少量配殿，不对应实际完整栋数。未制作鸿慈永祜/安佑宫、西峰秀色、日天琳宇、文源阁等完整景群，也未复原长春园全部附属建筑。绮春园完整1786范围、地盘和布局缺失，除正觉寺外不补造后期建筑。园外环境为简化地表，没有准确的18世纪周边村庄、农田和西山地貌。

步行限制到虚拟廊道与景点观景区；建筑内部、迷宫内部、多数台基不是可进入空间。围墙及次要小构件碰撞尚不覆盖全部；主建筑用外接矩形限制，安全区域有保守余量。不能把它当现实游客开放路线或现场导航。没有声称把所有历史桥梁复原；桥面是区分颜色的虚拟连通设施。

## 提高精度需要的具体资料

1. 清宫1786或前后可确认未改建的三园地盘原图，高分辨率扫描、档号、比例尺、标尺和至少六个可定位控制点。
2. 样式雷各建筑分期地盘、立样、丈尺尺寸、彩画样、工程活计档；确认属于实际建成状态，排除同治拟建图。
3. 绮春园1769–1786原边界及春和园分期图，确定哪些地块尚未并入，不能直接借用嘉庆/道光平面。
4. 西洋楼二十幅1786原图的无透视变形高分辨率扫描，与石件实测、考古基址测量和保护图纸联合配准。
5. 文物授权摄影测量/激光扫描，包括葡萄花纹、券门、石兽、兽首、水盘与石屏风，附明确模型许可。
6. 原始彩画、琉璃色样、外墙灰饰记载与材料分析；有日期、房间号的内檐装修及陈设档案。
7. 历史地形、河道断面、水位及桥梁剖面；现代DEM也不能直接当历史高程。
8. 具植物名录和合法许可的近景树木资产，以及真实移动设备上的性能与交互测试。
