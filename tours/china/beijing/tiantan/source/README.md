# 天坛公园三维游园

基于 Three.js / WebGL 的可交互天坛公园场景。场景使用本地米制坐标，`1 世界单位 = 1 米`；X 指向东，Y 向上，Z 指向南，原点取 OpenStreetMap 中祈年殿建筑轮廓的中心。用 WGS84 经度和纬度按局部等距近似投影到米，不直接把经纬度作为 Three.js 坐标。投影表达式与原始数据在 [`scripts/prepare-map.mjs`](scripts/prepare-map.mjs) 和 [`research/osm-map.xml`](research/osm-map.xml)。

## 安装、启动与构建

需要 Node.js 20.19+ 或 22.12+。在 `tours/china/beijing/tiantan/source/` 目录执行：

```sh
npm install
npm run dev
```

访问 `http://127.0.0.1:5180/`。构建和预览：

```sh
npm run build
npm run preview
```

`dist/` 为静态网站，部署其全部内容到任意静态托管服务。`vite.config.js` 使用相对 base，可放在子路径。运行场景不向外部 CDN 请求脚本、贴图或模型；地图数据、几何体、程序生成材质都在项目内。地图源数据更新时执行 `npm run data`，从 `research/osm-map.xml` 重建 `public/data/layout.json`。

## 操作

- 鸟瞰：拖动旋转、滚轮缩放、右键平移，移动设备可单指旋转、双指缩放/平移；“全园”和“重置”在底部。
- 步行：WASD / 方向键移动，Shift 快走。拖动鼠标转向；点击场景可锁定鼠标，Esc 释放。步行视高 1.7 米。
- 左侧按钮和右下可折叠地图用于跳转；点击建筑范围弹出简介，链接对应资料来源。
- 流畅 / 标准 / 精细画质调整像素比、阴影和树木 LOD。全屏 WebGL 随窗口更新。

## 模型范围

本地 OSM 路径保留主要全园路网与公园轮廓。重点模型包含祈年殿、三层圆台与围栏、皇乾殿及祈年门等院落建筑、皇穹宇/回音壁、圜丘、丹陛桥、斋宫/护城河、神乐署、长廊、围墙和出入口。4,700 棵程序化柏树由 InstancedMesh 依区域和道路分布，树冠、侧枝、树皮颜色与宽高有变化。祈年殿屋顶采用分段曲面 Lathe 几何与实例化瓦垄，另建檐口瓦头、层叠斗拱、彩画分格、门框、匾额和石栏板；三段正南御路石采用独立斜面。石、砖、蓝瓦、树皮及彩画均使用项目代码生成的局部 CanvasTexture，运行时无外部素材请求。

## 精度边界

**已核实：**祈年殿通高 38.2 米、外檐柱间直径约 24.2 米；皇穹宇殿台通高 19.5 米、直径 15.6 米；丹陛桥长 360 米、宽 30 米、北端约高 4 米；圜丘三级坛面直径 54.91 / 39.31 / 23.65 米。建筑群顺序和相对方位与官方导览、OSM 轮廓一致。

**从地图/照片推算：**祈年殿三层台基半径和分层高度、檐口高度/曲率、院落局部高差、出入口通行宽度与建筑立面分格。OSM 轮廓具有众包地图误差；部分场景坐标和官方尺寸之间经过校准，不能当成测绘成果。当前 OSM 公园外轮廓计算约 198 公顷，与公开资料常见的 273 公顷“天坛占地”口径不同，尚无官方现状边界测绘文件可以消除口径或边界差异。

**近似/简化：**彩画为按照片色彩和分格制作的程序图案，匾额为可辨识的示意构件；未复原具体纹样、字形书法、斗拱榫卯和石雕纹饰。台阶御路石、檐口瓦头和栏板虽有立体几何，形制仍依据照片推算。楼内不开放；园林树种、树龄与单株树精确坐标未知；部分广场、壕沟及次要附属建筑使用概略几何。回音壁没有声学仿真。部分围墙门洞和内院未逐一测绘，碰撞可保护主要游线，不代表真实游览限制。场景仍是研究型近似复原，**不是测绘级数字孪生或照片级复刻**。

进一步提升精度需要官方 1:500 或更高精度总图、建筑测绘立面/剖面、檐口与台基尺寸、现场标定摄影及单株古树 GIS 清单。详细参考与许可见 [`REFERENCES.md`](REFERENCES.md)。

## 验证

```sh
npm test
```

Playwright 在实际 Chromium + WebGL 中测试交互、路线与构建资源，输出 [`evidence/test-results.json`](evidence/test-results.json) 及各视角截图。正面细节截图另见 [`evidence/11-prayer-front.png`](evidence/11-prayer-front.png)，可运行 `node scripts/realism-shot.mjs` 重拍。2026-09-30 在 Windows 10 / Headless Chrome 151 / RTX 4070 / 1440×960 下复测，23 项检查全部通过；全园静止鸟瞰的标准画质约 60 FPS、136 draw calls、233 万三角形。测试脚本默认需要 `npm run dev` 服务；可用 `TIANTAN_URL` 改地址。帧率受该测试机 60 Hz 上限影响，不代表所有设备或复杂步行角度。
