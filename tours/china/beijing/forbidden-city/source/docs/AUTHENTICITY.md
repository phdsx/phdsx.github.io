## 年代基准

2026-09-30视觉修订：材质、重檐衔接、灰色台面、三层石栏、枝叶和脊吻轮廓已更新。[本轮方法、对照与估算范围](REALISM-REVISION.md)。太和殿脊吻预留1.90米、乾清宫1.45米为照片比例估算；最高点受原通高约束，没有新增测绘精度依据。彩画为原创简化几何纹样，不能解读为现状文物纹样复制。

当代故宫既存室外建筑格局。主要参考照片为故宫博物院网站 2020 年前后的图像，地图为 2026-09-28 的 OSM 官方 API 快照。使用既存建筑形制：太和殿为康熙重建后的形制，太和门为光绪火灾后重建形制，钦安殿不加入已拆除的乾隆抱厦。这些是同时存在的现状建筑，不是把各自始建年代混作一个历史复原时期。

**没有取得故宫全域测绘成果、修缮工程模型或逐栋立面图。全域覆盖指地图空间范围，不表示所有建筑外观已经完成核对。** 当前也不表现临时施工、2026 年当日开放路线或刚完成修缮后的精确色彩变化。

## 坐标与场地

官方建筑总览给出东西 753 m、南北 961 m、城墙高约 10 m、护城河宽 52 m。采用这些数值作为世界米制约束。

OSM 边界 relation 9511883 的城墙交点：

|锚点|经度 WGS84|纬度 WGS84|
|---|---:|---:|
|西南 SW|116.3866043|39.9122127|
|东南 SE|116.3953903|39.9125310|
|西北 NW|116.3862020|39.9208780|

注意午门雁翅楼向南突出，不能用整个边界最低纬度当作南墙纬度。

对经纬度点解 `P = SW + u(SE-SW) + v(NW-SW)`，再转换 `x = 753u - 376.5`、`z = 480.5 - 961v`。原点为理想化城墙矩形中心，x 沿南墙向东，z 沿西墙向南，y 向上，1 单位 = 1 米。这是局地仿射标定，保留地图相对布局；不是地理测绘投影或误差校正。北墙端点的轻微非平行和真实城墙局部变形未保留。场地格网北相对真北约向西偏 2.04°，具体建筑的局部偏转尚未逐栋标定。

所有原始轮廓、数据名称和分类来源保存在 `layout.json`。运行中的多数单体采用轮廓包围盒或矩形分解，复杂轮廓的屋顶相较原图有简化，不能把保存的高点数轮廓等同于精确复合三维模型。

## 已实现与未完成范围

### 有公开尺寸约束

### 已按资料分别处理的外观

中轴线：午门—太和门—太和殿—中和殿—保和殿—乾清门—乾清宫—交泰殿—坤宁宫—钦安殿—神武门。保留各自单/重檐、庑殿/歇山/攒尖/盝顶差别。文华殿、武英殿分前后殿与连接廊。四角楼用十字形及内外不同抱厦，复合屋顶仍简化。万春亭/千秋亭表现上圆下方与四面抱厦。弘义阁与体仁阁表现两层与腰檐。

### 全域地图层覆盖、外观未逐栋核对

东西六宫配殿与后殿、外东路宁寿宫、外西路寿康宫/慈宁宫/慈宁花园、养心殿及邻近宫院、乾东西五所、御花园边缘建筑、值房和廊庑等。保留地图轮廓、间距、路网与院墙，建筑多为示意几何。当前 1228 条建筑/城台/院墙轮廓不是 1228 座完整精细建筑，也不是故宫现存单体总数。

### 尚未还原

- 延禧宫灵沼轩主体：地图区域保留、关闭步行穿入，仅呈基础示意。地图门洞不代表现实开放。
- 完整的七十二脊角楼结构、脊兽雕刻、大吻龙形、台基龙头排水、九龙壁浮雕、丹陛石雕纹样。
- 逐扇现状门窗，真实彩画纹样、斗栱模数、完整金柱柱网、构件榫卯与结构细节。
- 假山、古柏形态、乾隆花园各进院落的精细景观和叠石；树木只采用107个地图标记的近似树冠。

- 对低/中/高画质以外的移动设备专项调优和长期稳定性测试。
