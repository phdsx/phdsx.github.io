# 坐标、尺度与精度

## 坐标一致性

原点 WGS84 `(116.273°E,39.99°N)`。地球半径6378137m，`x=R·cos(lat0)·(lon-lon0)`，`z=-R·(lat-lat0)`（角度转弧度）；X东、Z南、Y上，1单位1m。园区约数千米，局部平面比例误差小于0.1%；这不意味着地图自身位置误差小于0.1%。地图与地形皆按WGS84处理，未叠加GCJ02/BD09。真北在小地图向上。

湖水面Y=0；DEM昆明湖样点原始值48.99609375被减去作为相对高程参考。未取得国家水准点，也未确认原瓦片统一垂直基准，不能把Y当成国家1985高程。12m采样网格是渲染采样间隔，不是12m精度；底层DEM分辨率及树冠、建筑影响仍存在。

## 核对与限制

已将官方导览图和公开米制图进行人工布局核对：南湖岛位于主湖东南侧并接东堤；西堤分隔湖面；万寿山在北部，长廊位于前山沿湖；后湖/苏州街在北坡，谐趣园在东北侧。此核对确认拓扑和相对方位，没有可据此计算的测量RMSE。

官网远景照片用于前山中轴和湖上视线比对；佛香阁仰视照片用于檐口、柱列、梁架和窗棂；桥梁照片用于栏杆及狮子；石舫官方照片用于舱楼与船形辨识。存在照片视觉近似，不能宣称正、侧立面已逐点匹配。

仍存在：地图位置误差未量化；局部院落/岸平台高程估计；佛香阁楼层与屋檐比例差异；部分未命名建筑共享形态；窗棂、斗栱和彩画缺少文物级细节；石狮缺少个体雕刻；植被密度、树种与位置误差；水体倒影采用384px平面反射且按8/12帧更新，会有低分辨率和运动时延，低画质关闭倒影；部分偏离主要路线的陡坡限制行走。基础碰撞针对室外游览，不能代替完整建筑物理碰撞。

提高精度需要：统一坐标及垂直基准的园界/岸线/道路测绘；厘米至分米级地形或LiDAR；各核心建筑平面、剖面、檐口和台基标高；允许使用的多角度照片/摄影测量或独立模型；树木调查；准确的步道与桥阶纵断面，以及可发布素材授权。
