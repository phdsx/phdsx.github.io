## 证据等级

**已核对的来源事实**：北园与南园是独立地图对象；四处景点有官方介绍；温室位于中轴路西侧，官方描述倾斜玻璃顶棚；樱桃沟保育水杉；曹雪芹纪念馆始建于1984年。这里“已核对”不等于几何已测量。

**有源但未独立实测的几何**：OSM边界、道路中心线、水体多边形、29处建筑轮廓、景点定位。它们与原始WGS84几何保持毫米级数值一致，但现实中的偏差未知。

**估算部分**：温室曲面形态、高度约10–29m及骨架间距；其他建筑统一6m粗模（有真实height标签时采用标签）；道路默认宽1.8–5.5m；湖面和桥面标高；建筑基座整平；种植分区、树型、树高、个体数量和位置；上午光照方向与强度。无资料建筑使用平顶轮廓体块，没有补画辨识性飞檐、殿宇、雕塑或文物。

**缺失部分**：法定全园边界与山地管理范围、高分辨率正射、可靠地表模型、各楼高度/屋顶/立面尺寸、近景多角度测量照片、古树与种植清单、栏杆座椅灯具位置、独立现场控制距离。未找到的设施不自行补造。

## 坐标和高程

输入 OSM 为 WGS84。坐标原点 (116.2025°E,40.001°N)。水平转换先计算 WGS84 椭球 ECEF，再取切平面的 East 和负 North。Y来自DEM相对高程，原点数值保存于 scene.json。没有将数字导览图配准，没有引入 GCJ-02/BD-09。

Terrarium 解码：`h = R*256 + G + B/256 - 32768`。瓦片像元按 Web Mercator 网格定位；经纬度在进入场景前再转换为当地米制，不把 Web Mercator 平面距离当真实米数。地形未做垂直夸张。

湖泊内地形降至估算水面下；10m范围平顺过渡；建筑周边2m范围与基座平顺衔接。上述地表改动和桥面高程用于接触关系与碰撞，应由实测数据替换。DEM可能包含树冠/建筑信号，不能视作纯裸地DTM。

## 许可交付

OSM数据及衍生数据库遵循 [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/)，页面持续署名且提供原始与衍生数据。程序代码许可证不覆盖第三方数据。地形完整归因文件随瓦片交付。官方受版权保护的照片和导览图仅保留链接；研究中读取的官方网页没有作为素材再分发。

原始查询曾在 Overpass 超时，最终使用 OpenStreetMap 官方 API 获取；没有将失败的请求当作已有数据。

温室外立面最终使用有色反射玻璃的非透明代理材质，避免多层透明面带来的严重近景过绘；不是透射玻璃/真实内景的复原。对照截图展示这一限制。
