# 国家植物园北园 · Three.js 米制交互场景

本站已接入「3D云游 → 中国 → 北京」。`index.html` 提供站点导航，原三维工作区保留为 `scene.html`；以下为原项目说明。

这是**已经能运行的地理重建原型**。交付了开放数据粗模、温室材质样板和完整浏览交互；**未完成测绘级 1∶1、全园精细建模或照片级验收**。

## 运行

安装 Node.js 18 或更新版本后，在本目录打开终端：

```sh
npm start
```

浏览器打开 <http://127.0.0.1:8086>。入口为根目录 `index.html`。Windows 也可双击 `start.bat` 启动服务，再打开上述地址。无需 `npm install`，所有运行依赖、地理数据和程序材质均已本地化，不依赖 CDN。也可以执行 `python -m http.server 8086 --bind 127.0.0.1` 后访问同一地址。不能直接双击 HTML：浏览器会限制 ES 模块和 JSON 读取。

## 操作

- 鸟瞰：左键旋转、滚轮缩放、右键平移。点击景点卡片或标记平滑定位。
- 地面漫游：WASD / 方向键；Shift 以 2.8 m/s 快走，普通步行 1.4 m/s；拖动视线或单击锁定鼠标，Esc 释放。
- 视高 1.65 m。跟随处理后的地表；限制进入已绘建筑、水体、园界外和陡坡。带 OSM 桥梁标签的道路提供估算高程的桥面通行。
- 小地图固定北向，鸟瞰显示观察中心，漫游显示眼位投影；箭头显示朝向。点击地图可定位。
- 俯视、返回初始视角、显隐标记、截图、高中低画质；触屏支持拖动视线和方向按钮。
- “资料与精度”可查看证据等级，并对当前视角运行 5 秒帧率检测。点击官方来源链接会访问外网；场景自身无需联网。

## 交付文件

- `src/geo.js`：WGS84 → 米制局部坐标、逆变换、DEM 插值、碰撞。
- `src/scene.js`：地形、道路、水体、建筑、程序材质、实例化植被与 LOD。
- `src/main.js`：交互、UI、加载错误、性能采样。
- `data/source.geojson`：保留 WGS84 的裁剪后 OSM 源几何；ODbL 1.0。
- `data/scene.json`：局部米制数据、原点、来源状态、估算属性和控制点。
- `data/source-archive/`：获取的原始 OSM 快照、请求清单与哈希。
- `data/terrain-source/`：原始 Terrarium 瓦片与来源署名。
- `docs/SOURCES.md`：逐类来源、日期、精度、许可与缺失清单。
- `docs/VALIDATION.md`：三处尺度核验、功能与性能实测、阶段验收状态。
- `docs/comparison.html`：源数据地图、实际场景截图和实景参考的对照。
- `docs/screenshots/`：浏览器实拍截图；不是生成效果图。

## 核心约束

原点 WGS84 经度 116.202500°、纬度 40.001000°；1 世界单位 = 1 米，X 东、Y 上、Z 南。水平坐标由 WGS84 椭球 ECEF 投影到原点切平面；Y 为 DEM 高程减原点 DEM 高程，**不是 ECEF Up**。这一明确分离便于更换测绘 DTM。没有使用 GCJ-02、BD-09 或未经配准的导览图坐标。

OSM 北园关系 `8758747` 与南园对象 `661458570` 分离，所有对象按北园关系裁剪。该北园映射面积约 **117.3 ha**，不能等同于官方法定/规划面积。园外仅为同一低分辨率 DEM 的上下文地表，不含南园建筑、道路或景点。樱桃沟标记借用有源坐标的“水源头”点，不冒充整个景区中心。

当前有 429 段道路、7 处水体、29 处建筑轮廓。8,029 株程序树按北部林地、东部园区、中央园地等粗分区布置，树种分配、个体位置和树高均为估算；数量不是树木普查统计。树冠避让道路、建筑、水体和已识别院落。

## 更新与校验

```sh
npm run check
npm run build
```

`check` 对源几何、坐标往返、南园排除、碰撞、树冠避让和三处椭球距离做自动验证，生成 `docs/validation.json`。`build` 生成可用任意静态服务器托管的 `dist/`。验收报告中包含当前设备的实际帧率，不保证其他设备同样表现。

重新生成数据需要 Python 3.10+、Pillow、Shapely：

```sh
python scripts/prepare_data.py --source data/source-archive
```

原始 DEM PNG 和 ATTRIBUTION 需放入该输入目录或按代码所示提供；交付归档已包含可重建副本。程序会裁剪数据、保留许可信息、确定性生成植被，不会自动从互联网抓取或将未知坐标当 WGS84。

替换真实数据时：先核实合法来源和 CRS；以 WGS84 写入源 GeoJSON；用同一局部原点重算所有要素；给高度、宽度、屋顶和材质增加独立来源。`heightStatus`、`widthStatus`、`status` 不应因为画面更精细而改成“已核实”。

## 优先补充的资料

1. 北园法定/管理边界，含樱桃沟及山地区域；允许使用的 10–20 cm 正射影像和独立控制点。
2. 裸地 DTM / LiDAR、湖面标高、桥面高程、道路纵横断面。
3. 温室屋顶结构与外轮廓测绘，卧佛寺与纪念馆平立剖图；至少三处独立实测尺寸。
4. 带拍摄方位、日期、焦距和可重用许可的多角度照片；树木普查、道路附属设施分布。

在这些资料补齐前，温室曲面、其他建筑高度与平顶粗模都不应用于设计、测绘、导航或文保决策。
