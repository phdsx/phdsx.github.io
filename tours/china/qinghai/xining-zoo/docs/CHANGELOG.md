# 版本更新

## 0.2.0 · 2026-10-04

修正了地图图层与地形表面不一致的问题。此前行走高度用双线性插值，而 GPU 绘制的是分片三角面；在这片 DEM 的网格中点，二者最大可差 0.645 米。道路或大面积填色只在顶点贴地，跨越坡折时也可能切入地形。以上属于工程内部数值问题，与现场测量误差不同。

- 运行时高度直接匹配 Three.js 地形三角面，步行相机保持其上方 1.65 米。
- 道路、建筑占地填色和水面范围标记按地形三角边切分；轮廓线和等高线同步贴合。原 UV 插值与平面覆盖范围保持不变。
- 10 米 / 20 米两级地形与各地图图层同步切换；图层隐藏在切换前后都生效。
- 加载清单包含场景、导航、地形贴合模块；其中任一文件缺失时保留失败提示。
- 步行时隐藏鸟瞰定位圆柱，避免误读成建筑。触屏使用摇杆与拖动转向，隐藏不适用的鼠标锁定按钮；移动端步行提示移到上方，避开小地图。
- 新增独立射线测试、非共面合成地形测试、面片面积与朝向及 UV 检查、两级 LOD 同步检查、模块 404 检查；补强触控实际位移与转向断言。

原始 OSM、DEM 和派生地图/高程 JSON 未改变。没有新增未经核实的门楼、道路连接、场馆高度、植被或动物。进一步公开检索仍没有找到足够的入口尺寸及现场控制点，见 [补充检索记录](REFERENCE-RESEARCH.md)。

测试数值与软件渲染性能见 [验收报告](ACCEPTANCE.md)、[几何检查原始结果](surface-test-results.json) 和 [浏览器检查原始结果](test-results.json)。射线一致性只证明程序内部匹配，不代表地理测绘精度。
