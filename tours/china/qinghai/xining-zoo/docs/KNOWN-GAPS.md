# 未完成部分与最优先资料

当前阶段只完成数据支持的空间核对底座。用户要求的写实主入口—主干道—代表性展区，还没有达到可以扩展全园的质量标准。

## 优先级 P0：决定能否开始准确建模

1. **现行园界与主入口**：近期园方平面图、带比例尺和北向的正射/卫星影像，确认 53 公顷社区图与 100 公顷历史介绍的差异。
2. **入口及一段道路**：正面、两侧、背面照片；拍摄日期、位置、方向；入口净宽与总高、道路宽度、高差。新门于 2021 年启用，老入口图片不能直接代表当前入口。
3. **一个指定展区**：明确展区名称，提供平面边界、建筑高度、围栏与游客区域、多个方向照片。先做这一段，再制定写实质量标准。
4. **三个照片机位**：原始照片（保留 EXIF）、拍摄位置/方向、焦距或视野，至少一个已知尺寸；确定统一场景日期和天气。

## 仍未建模

- 真实门楼、检票闸机、建筑屋顶、立面、窗门、标识。
- 真实台阶、坡道断面、路缘、挡土墙、护栏、展区围栏。
- 草地与裸土实际分区、乔灌木的品种与位置、岩石与湖中岛。
- 长椅、路灯、垃圾桶、指示牌的现场形状与位置。
- 动物活动区、来源合规的动物/植物 GLB、真实体型与行为动画。
- 现场材质 base color / roughness / normal / AO 贴图及实际 UV 尺寸。
- 参考天气的太阳、环境贴图、接地阴影和真实玻璃/金属表现。

## 尚不能作出的保证

- 不能称为全园 1:1 复原、精确地形或真实建筑比例。
- 不能保证地图道路都是游客可走道路。当前的通行限制只是浏览器导航规则，不是现场路线建议。
- 没有围栏数据，因此碰撞只保护已录入的建筑平面、水面、园界和参考道路边缘，不能声称已验证所有围栏。
- DEM 不能解析馆舍和挡墙，贴地行走不代表台阶已正确还原。
- 三个检查相机不是已经匹配照片的机位，没有通过轮廓、相对位置、高差、材质或植被一致性验收。
- 没有在实体独立显卡电脑、真实手机、Safari 或 Firefox 上做性能兼容验证。

## 工程待扩展

当前运行资源约数 MB，全量本地载入。已实现地形 LOD、视锥裁剪、DPR 限制；无后期效果和实时阴影开销。

按区域加载/卸载 GLB、实例化植被、KTX2 纹理与 Meshopt/Draco 压缩尚未启用，因为没有可接受的现场资产。随包的 GLTFLoader 是后续扩展依赖，未在当前场景使用，不能把它的存在算作已完成模型加载。

获得资料后的顺序：核对边界与尺度 → 校准入口/道路/单展区 → 建立真实几何与材质 → 完成三机位配准 → 再扩展其他区域与资产流式加载 → 实体目标设备验收。
