# 西宁野生动物园 · Three.js 空间资料核对版

本站已接入「3D云游 → 中国 → 青海」。根目录 `index.html` 提供站点导航，三维工作区仍位于 `dist/index.html`；以下为原项目说明。

**版本 0.2.0，整理日期 2026-10-04。当前是可运行的资料核对工程，不是写实成品，也未通过“1:1 还原”验收。**

用户尚未附上地图、现场照片、视频或尺寸。项目已据公开资料实现能够支持的部分：公开高程地形、社区地图布局、浏览控制与可追溯的数据结构。未猜造门楼、建筑立面、展区围栏、植物和动物。

## 运行

Windows 可双击 `启动预览.cmd`。也可使用 Node.js 18 或以上版本，在本目录运行：

```sh
node server.mjs
```

打开 <http://127.0.0.1:4173/>。不需要 npm install；Three.js 已随项目附带。停止服务时按 Ctrl+C。端口被占用可运行 `node server.mjs 4174`。

也可用 Python：

```sh
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

请通过 HTTP 服务打开，不要直接双击 `dist/index.html`：ES Modules 与本地 JSON 读取需要 HTTP。浏览器需支持 WebGL 2、ES Modules 和 import maps，推荐近期 Edge / Chrome。运行时不依赖外部 CDN。

## 已实现

- **1 世界单位 = 1 米**；WGS84 经纬度转换为局部平面坐标，X 向东、Y 向上、Z 向南。
- Mapzen Terrarium 高程解码地形，10 米采样网格、10 米等高线；10 米采样不代表 10 米原始精度。
- 34 条地图道路、28 个建筑占地轮廓、3 个水面/展区范围要素；无实测高度的建筑不拉伸为虚构建筑。
- 鸟瞰旋转、缩放、平移；步行眼高 1.65 米、WASD、拖动转向、可选鼠标锁定、Esc 退出。
- 步行限制在参考道路范围，阻挡建筑轮廓、水面及已记录的园界；分步碰撞避免高速越界。
- 地点列表、详情来源链接、地图定位、小地图与朝向、图层开关、画质选择。
- 手机布局、触控摇杆和转向、自动降低像素比。
- 本地资源加载计数与字节进度、失败提示、WebGL 上下文丢失提示。
- 地形与道路、轮廓、水面标记、等高线使用同步两级 LOD；视锥裁剪、DPR 上限。
- 行走高度与实际地形三角面一致；道路填面和轮廓沿地形三角边切分，避免跨坡悬空或穿插。
- 三个可重复载入的**未标定检查视角**，用于记录照片对照缺口。

默认展示鸟瞰。当前主入口坐标与朝向未核实，不能把猜测位置设为“真实主入口”的初始镜头。步行入口是地图北侧道路附近的有效落点，页面明确标为待核。

## 操作

|模式|操作|
|---|---|
|鸟瞰|左键拖动旋转、滚轮缩放、右键平移；触屏单指旋转、双指缩放/平移|
|步行|WASD 或方向键移动，按住 Shift 加速，景观上按住拖动转向|
|鼠标锁定|点击“锁定鼠标”；按 Esc 或再次点击按钮退出；浏览器不允许时仍可拖动转向|
|手机|左下摇杆移动，在景观上拖动转向|
|定位|点击地点查看依据，再点“到附近道路”；小地图点击会吸附到附近参考道路|
|检查机位|“查看还原边界”对话框最下方的 P1 / P2 / P3；均未做照片机位标定|

## 还原与验收状态

最重要的不确定性是：OSM 边界约 **53.0 公顷**，而市政府 2020 年介绍为 **1500 亩（约 100 公顷）**。范围或统计口径未查清，不能把当前多边形视为测绘边界。

道路显示宽度为 6 米或 2.5 米，是工程参数，不是实测值。建筑高度、立面、入口、围栏、挡土墙、台阶、植物位置和动物活动区仍缺少足够依据。地形为区域 DEM，不能分辨真实台阶、护坡或挡墙。水面填色仅表示地图范围，不代表测量水位。

PBR 渲染管线已经配置，但目前的中性色材质是读图材质，**不是现场材质复原**。没有把简单几何体植物/动物作为成品。高质量 GLB、PBR 贴图、按区流式加载和植被实例化须在位置资料与有授权的资源就绪后实施；当前不声称它们已完成。

## 文件结构

```text
dist/                  可直接放到静态 HTTP 服务的网页
  index.html           中文界面
  style.css            桌面、手机和对话框样式
  js/bootstrap.js      加载进度与失败处理
  js/main.js           场景、相机、交互、小地图、LOD
  js/spatial.js        坐标、地形采样、碰撞与道路导航
  js/surfaces.js       图层贴合地形、线段切分与等高线
  assets/data/         带来源与未确认项的派生数据
  assets/vendor/       Three.js r180、OrbitControls 及许可
source-data/           OSM XML 与原始高程瓦片
tools/prepare-data.py  从原始数据重新生成 JSON
tools/browser-check.cjs  可复现浏览器检查（可选，需 Playwright）
tools/surface-check.mjs  独立射线与几何检查（Node.js，无额外依赖）
docs/                  来源、缺口、测试、截图
server.mjs             无外部依赖的本地服务
```

修改资料时保留原始来源 ID、时间戳与置信状态。若用高德/百度坐标补图，须先确认 GCJ-02 / BD-09 与 WGS84 的坐标差异，不能直接叠加。

可选数据重建：安装 Python 与 Pillow 后运行 `python tools/prepare-data.py`。这只重复现有数据转换，不会自动补充缺失资料。

## 下一阶段所需资料

优先补充：带比例尺及北向的近期园区图；现行主入口的正面、侧面照片与宽高；从入口到水禽湖的连续道路照片、道路宽度及高差；一个指定展区的平面边界、建筑外观和围栏资料。每张照片尽量带拍摄日期、位置、方向和一个已知尺寸。
