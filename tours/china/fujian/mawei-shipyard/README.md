# 马尾船政 · 五大片区三维网页

入口为本目录 `index.html`。本版将原来的约350×220m船厂核心样板，扩展为连接**船厂、官街、马限山、旧港、罗星塔**的约1.77×1.57km建模窗口。交付可运行的Three.js米制场景、可追溯的地图布局、山地步行和局部外观样板。**新增区域仍是布局/形制阶段，未达到全区照片级或测绘级1:1。**

## 启动

Node.js 18+；现代浏览器需支持WebGL2、ES模块和import maps。运行不需要npm install或地图密钥。

```powershell
cd D:\code\html\phdsx.github.io\tours\china\fujian\mawei-shipyard
npm start
```

打开 http://127.0.0.1:5191/ 。`PORT`环境变量可换端口；也可将整个目录部署至静态HTTP服务或GitHub Pages。不要以file协议双击HTML。Three.js **0.180.0 / r180**与同版OrbitControls、BufferGeometryUtils、Reflector已本地交付，无运行时CDN或在线地图依赖。

## 坐标、尺寸与地形

原点 **119.4431389°E、25.9905083°N**（绘事院地图轮廓包围盒中心）。WGS84 / EPSG:4326点转ECEF，再投影局部ENU；Three.js **x=东、y=上、z=南，1单位=1米**。逆变换交WGS84椭球求解。未混用GCJ-02或BD-09。

原船厂环境从发表总平面手工读图，以绘事院/博物馆两中心相似配准；规范化图幅1888×1334、尺度约0.235208m/像素。12处主体OSM轮廓，2处辅助体量来自总平面。细节墙体按同轴外包矩形简化；原多边形另存，碰撞覆盖渲染外包范围。六个独立读图点与OSM顶点均值差异 **2.46–8.30m**；两来源都不是现场测量，不能当绝对精度或误差上限。

新增主体使用OSM多边形/关系外环、院落孔洞和点位。高度除明确资料外为估算。罗星塔官方存在**30m/31.5m**两种总高口径；模型采用31.5m并保留冲突。昭忠祠地图外环约24.9×36.7m与官方25.1×37m文字大致相容；据此调整长短轴，不构成独立测绘验收。天后宫是**用地轮廓**，内部两进院落与殿宇尺寸为估算，未把85m用地宽直接当成一栋大殿。

Mapzen两张z14 Terrarium瓦片按 `R×256+G+B/256−32768` 解码。瓦片EPSG:3857采样转WGS84/ENU，显示高程减去原点样本6.616391m。源约30m或更粗；6m显示网格仅细分，不增加精度。船厂核心地坪设相对0；建筑平台、相邻学堂/医院共同地坪、池/坞坑及水底局部平整，基础挡台延伸至地面。江面约−2m、水位/岸壁/坞深均估算，没有独立国家高程基准或潮汐模型。

公园轮廓有地图支持；新增公园树冠按规则覆盖采样，排除建筑/道路附近位置，**不是逐树实测**。原核心树位来自总平面读图；树种、冠形和高度估算。

## 操作与渲染

- “全片区”鸟瞰全窗口；“船厂”返回原样板区；地点列表含五片区快捷按钮和16处定位。左键旋转、右键平移、滚轮缩放；触屏拖动/双指操作。
- 步行视点距**当地地面1.65m**，WASD/方向键1.45m/s，Shift3m/s；拖动观察，双击或按钮锁定鼠标，Esc释放。手机四方向按钮已实现。
- 建筑/复合院落、树干、池/坞、水域、船台及窗口边界有基础碰撞、小步移动和沿墙滑动；山体按与渲染一致的三角网插值跟随高度。核心木平台按15cm台阶处理。没有建筑内部漫游或现场开放权限模拟。
- 小地图显示北向、朝向、200m比例尺，支持点击定位。标签开关、画质、来源、截图导出、加载进度和失败提示已实现。
- 界面统一使用网格布局：地点列表限制在可用高度内滚动，介绍卡和小地图各占独立区域。900px及以下默认收起列表，选点后自动收起；窄屏工具栏分两行。地名按实际投影显示，避让控件和其他标签。窗口缩放同步更新步行按钮和操作提示。

物理材质、sRGB基础色、线性法线/粗糙度、ACES色调映射、固定日光方向、PMREM环境反射。CC0通用砖/铺装/抹灰/树皮与程序木材/屋瓦/金属；UV米制，砖公开模数约1.25m。通用贴图不是现场扫描。没有把带透视/固定阴影的立面照片贴到模型上。

江水为克制灰绿褐色、低幅波纹；核心景观池近景512px反射，远景/节能关闭。没有真实流场和完整岸边反射。没有泛光、景深或浓雾。扩大场景采用对数深度缓冲，避免远景道路/水面闪烁；道路几何裁切至地形三角形，避免宽路面穿入山坡。

| 画质 | 最大DPR | 阴影 | 近景池反射/叶片 |
|---|---:|---|---|
| 节能（触屏默认） | 1 | 关闭 | 关闭/半量 |
| 均衡 | 1.35 | 1024 | 最近池512px低频/完整 |
| 精细 | 1.75 | 2048 | 最近池512px低频/叶片投影 |

按栋和材质合批、95/220/420m细节裁剪、植被实例化、视锥裁剪；构建建筑时让出主线程。地理数据一次加载，**尚无远程分区流式加载**；本版不是高精度GLB资产库。广域地形及道路仍合批，真机移动性能需后续验证。核心依赖失败显示具体错误；可选贴图失败提示并使用程序替代；上下文丢失有提示。没有私密API密钥。

## 实际验收

2026-10-07：Windows_NT10.0.26200，i5-13600KF、31.8GB、RTX4070（ANGLE D3D11），无头Chromium151.0.7922.34，1440×960、DPR1。界面修复后重测，**64项浏览器检查、60项文件/语法/数据检查通过**。首屏ready约2977ms；七组3秒rAF采样（全区、绘事院、旧港、罗星塔及三档画质）均约60fps，P95约16.7–16.8ms。JSON保留完整采样和绘制量。不是长期压力测试、真机手机结果或所有显卡保证。

390×844为同一PC触屏模拟，验证基本浏览、移动和无横向溢出。界面修复另完成**11种尺寸、57个状态检查**（320×568至1440×960，含676×884侧栏、844×390横屏、1280×800触屏模拟及实时缩放），覆盖长列表、长地名、选点收起、步行控件、资料弹窗和标签避让，无重叠或越界；见`evidence/ui-layout-results.json`和`ui-*.png`。早期全景取景检查保存在`responsive-checks.json`。**未测试真实手机、其他浏览器或高DPR设备**。软件检查不能证明1:1测绘准确性或照片级画面。`comparison.html`展示实际渲染，并链接原始实景；未取得原摄影机位/焦距，只有近似同向对照，未宣称严格同角度配准完成。
