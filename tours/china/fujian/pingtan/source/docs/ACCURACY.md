# 精度、近似和缺失

当前交付为真实空间底图与有限石厝样板；**未达到整岛实景摄影测量或测绘级数字孪生**。不能用于规划、测量、施工或航海。此处精度描述的是实际来源与处理，不将可视化细分当作数据升级。

## 数据准确还原（相对于源数据）

- WGS84 经纬度转换为 UTM 50N，局部原点 `[119.78,25.53]`，1 单位＝1 米。未缩放岛屿、高程或景点距离。UTM 是网格米，含投影畸变；没有独立实地控制点验证。
- 主岛岸线 3779 个原始节点组成闭合环；保留当前 OSM 轮廓和方位。UTM 包络 21.236×30.032 km；计算面积 289.203 km²，含地图中现有填海，不能等同历史/官方面积。
- 下载到 4992 条地图道路，支持的类别渲染约 4532 条；每条中心线保持坐标，未画虚构连接路。道路材质、宽度、高架高度未测量。
- 394 处已映射建筑保留平面轮廓；全岛覆盖远不完整。未用随机房屋填补数据空白，历史影像中的屋顶分布仍可见。
- 180 个风机点位来自 OSM，含陆地和附近海上点。未映射的机组不会自动补造。
- 原 DEM 1 角秒采样约 28×31m，40m 运行格网；附近 40m、远处 80/160m 网格。显示插值不提高原资料分辨率，未宣称厘米或米级垂直精度。
- 2016 真实影像重投影到米制纹理，空间关系可核对，非现状影像。

## 参考照片近似建模

北港 `w611957434`（一方青石）与 `w611957440`（九月美宿）的 OSM 轮廓保留。立面、屋顶、窗门不是对应旅宿的照片复刻，而是当地石厝类型样板：墙高估计 6m，低坡瓦顶及压瓦石根据官方照片的共性形式制作。第二处复杂轮廓使用平屋顶近似。庭院小铺装、矮墙与灌木属于明确标记的示范细节，其位置未调查。

已映射林地内的单株按条件配置，位置/树种/高度未实测。北港岩石限制在真实岸线附近，但单块岩石形态与尺寸为近似。PBR 石材来自通用 CC0 扫描材质，叶片纹理由程序制作，均非当地正射影像。

未标注建筑高度按楼层或建筑类别估计，未标注道路宽度按类别估计，桥面附加约 7m 的视觉高度。未标注风机名义轮毂高暂取陆上 65m / 海上 115m，转子半径 0.36 倍高度；方向、转速与叶片形状是统一类型化近似，不是机组技术档案。

## 高程与海水处理

`elevation-raw.f32` 保留原始重采样高程。`surface.f32` 在岸距约 85m 范围内平滑接海，将海上渲染底面设为 -3m。Y=0 为视觉海面，没有实时潮位。岸距由 ~14m 栅格做欧氏距离变换，量化步长 4m，最大 508m。近岸约 220m 颜色渐变、约 19m 泡沫和米制波纹是视觉模型，**不是测量水深、礁石图或海浪预报**。

相机最低高度使用 40/80/160m 三档表面上包络加 2.5m，减少 LOD 切换造成的穿地；无建筑内部碰撞，近墙飞行仍可穿墙。天空随相机移动以保持远裁剪内可见，不缩放地物。太阳方向按 2026-10-07、CST 的近似公式；卫星图中历史烘焙阴影不会随时间移动。

仙人井约100米局部范围与镜沙约8×14米洞腔使用近似模型对应的视觉地面及离地保护；这些位置不使用原DEM粗地面阻挡洞内镜头。原始高程文件未修改，但局部显示表面有替换；不应将井口崖壁约43米标高解读为DEM或实测高程。洞壁和屋内没有完整实体碰撞。

## 仍需补充

近期亚米级正射影像或有使用许可的无人机三维瓦片；1–5m 裸地 DEM 与明确垂直基准；完整建筑轮廓/高度/立面；潮位与近岸水深；礁石、石厝街巷、树种与单株调查；风机型号及尺寸。完整高精度数据进来后再扩展地形、村落与风车近景，接口见 EXTENDING.md。

剩余视觉局限：远景接近卫星地形图，近景地表不具备无人机照片细节；两栋外观仍偏类型化；村落缺少多数三维建筑；地形分辨率不足以表现岩岸微地形；海水无实测深度；林地树冠为简化实例。没有把这些局限描述为“完整真实还原”。

## 本次海岸内容修订

独立显示 52 处真实 OSM 沙滩多边形，包括跨出自然岸线的潮间带；原始主岛岸线保持 3779 节点，不进行挪动。沙滩干湿颜色、纹理、约0.38m的 LOD 避让偏移和露出潮间带高度属于视觉处理。单独 water-field.png 仅为海面遮罩与浪花计算，将岸线掩膜与实际沙滩多边形合并；不覆盖原岸线掩膜或原 DEM。

风机保持原坐标，81 海上 / 99 陆上；全岛鸟瞰不再因相机高于18km隐藏机组。海上基础黄段、平台属于通用估计，单独提供海上机组定位。长江澳镜头改为能看到弧形沙滩、陆上风车与近海风车的视角。

新增龙王头红色双层观光车，外观按报道照片核对；尺寸、轨距、行驶速度估计。报道为约800m、3站，没有获取实测路线和两端商户坐标，所以示意轨迹严格约束在实际沙滩范围内，不能认作真实运营轨迹。

坛南湾按 w990631701 沙滩定位；北部岩岸与北港圆钝石岸沿实际岸线配置形态近似的礁石。这些提供海岸类别差异；镜沙黑洞、仙人井等具体地标仍未取得足够模型/位置控制资料，没有补造并宣称精确还原。
